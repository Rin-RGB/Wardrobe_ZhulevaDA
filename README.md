# Система формирования гардероба

## Назначение

Система предназначена для помощи пользователям в создании, хранении и управлении собственным гардеробом, а также в подборе готовых образов (комплектов одежды) под различные ситуации: повседневные выходы, работу, мероприятия, сезонные прогулки и т. д.

Основная цель — упростить процесс выбора одежды, систематизировать вещи пользователя и предложить логичные сочетания на основе имеющихся категорий и характеристик одежды.

## Целевая аудитория

- Люди, которые хотят упорядочить свой гардероб и избавиться от «нечего надеть».
- Пользователи, интересующиеся модой и стилем, желающие экспериментировать с образами.
- Специалисты, работающие с одеждой: стилисты, имиджмейкеры, консультанты по шопингу.
- Пользователи, которые хотят планировать покупки и избегать дублирования вещей.
- Начинающие пользователи, которым нужны подсказки по сочетанию одежды.

## Описание предметной области

Предметная область охватывает процессы учёта, классификации и подбора одежды. Пользователь ведёт список своих вещей, указывает их характеристики (тип, цвет, сезон, стиль, назначение и т. п.), объединяет вещи в категории и формирует на их основе образы.

Система позволяет:
- хранить информацию о каждой единице одежды;
- группировать одежду по категориям;
- создавать образы из нескольких вещей;
- повторно использовать удачные сочетания;
- учитывать сезонность, повод и стиль при подборе.

Ключевая идея — связать отдельные элементы одежды в целостные образы и сделать процесс подбора удобным и быстрым.

## Основные сущности

| Сущность | Описание |
|---|---|
| Пользователь | Владелец гардероба. Хранит данные о себе, своих вещах и образах. |
| Одежда | Отдельная единица гардероба: футболка, брюки, куртка, обувь и т. д. Содержит характеристики (цвет, размер, сезон, стиль, бренд и пр.). |
| Образ | Готовый комплект одежды, собранный из нескольких вещей. Может иметь название, повод, сезон и стиль. |
| Категория | Классификационная группа, объединяющая одежду по типу или назначению (верхняя одежда, обувь, аксессуары и т. п.). |

### Связи между сущностями

- Пользователь → Одежда: один ко многим.
- Пользователь → Образ: один ко многим.
- Категория → Одежда: один ко многим.
- Образ ↔ Одежда: многие ко многим (образ состоит из нескольких вещей, вещь может входить в разные образы).

## Основные функции

- Добавление, редактирование и удаление одежды.
- Указание характеристик одежды: категория, цвет, сезон, цена

## Полный функционал

- Создание и управление категориями одежды.
- Формирование образов из имеющейся одежды.
- Сохранение, редактирование и удаление образов.
- Подбор образа по заданным критериям (сезон, цвет).
- Просмотр статистики гардероба (количество вещей по категориям, возможное количество образов и т. п.).
- Формирование рекомендаций по сочетанию одежды.

## План развития проекта

1. **Этап 1. Базовая версия**
   - Реализация учётных записей пользователей.
   - Добавление и редактирование одежды.
   - Создание категорий.
   - Базовый просмотр гардероба.

2. **Этап 2. Работа с образами**
   - Создание и сохранение образов.
   - Привязка одежды к образам.
   - Фильтрация и поиск по гардеробу и образам.

3. **Этап 3. Умный подбор**
   - Подбор образа по поводу, сезону и стилю.
   - Рекомендации по сочетанию цветов и типов одежды.
   - Учёт погодных условий.

4. **Этап 4. Расширенные возможности**
   - Загрузка фотографий одежды.
   - Статистика и аналитика гардероба.
   - Планирование покупок и список желаемого.
   - Экспорт гардероба и образов.

5. **Этап 5. Мобильность и интеграции**
   - Мобильное приложение.
   - Синхронизация между устройствами.
   - Интеграция с онлайн-магазинами и сервисами стилистов.
   - Социальные функции: обмен образами, публичные подборки.
